    5.0 本章解决什么问题

    这一章解决你从"机器学习会处理表格"到"机器能看懂图、听懂声音"之间的一串疑问：图像和信号这些"非表格"数据，凭什么机器也能学会？神经网络到底怎么工作的？我怎么亲手训练一个能检测零件缺陷的小模型？

    老张，40 岁，某机械厂质检科资深工程师。第 4 章里，他用 sklearn 把设备异常分类做出来了，表格数据机器学得会。可他很快发现一个尴尬：车间里真正的老大难是"看"和"听"——零件表面有没有划痕、气泡、毛刺，靠质检员肉眼盯着看，一天看几百件，看得眼花；设备有没有异响，靠老师傅耳朵听，听走神就漏掉。

    他问同事："这活儿能不能也交给机器学习？"同事说："能啊，但你得先把'缺陷长什么样'设计成特征——颜色深浅、纹理粗细、面积大小……"老张一听头大：缺陷千奇百怪，特征怎么设计得完？

    这一章要告诉你的是：深度学习就是为这种"特征太难设计"的问题准备的。它不要求你人肉设计特征，而是让网络自己在数据里学会"看什么"。学完这章，你会亲手训练一个能区分"正常 / 划痕 / 气泡"的缺陷分类小模型——虽然数据是程序合成的简化版，但训练、评估、排错的全套功夫都是真的。

    5.1 从神经元到神经网络

    5.1.1 神经元：一个"加权求和 + 阈值判断"的小单元

    先看神经网络最小的零件——神经元（Neuron），也叫感知机（Perceptron）。它做的事用一句话就能说清：

    把几个输入分别乘上权重，加在一起，再过一个判断，输出一个数。

    写成数学就是一个公式：

    输出 = 激活函数( w₁×x₁ + w₂×x₂ + … + b )
    • 输入 $x_1, x_2, \dots$：比如"直径 20mm""转速 1500rpm"这类数值；
    • 权重 $w_1, w_2, \dots$：每个输入的重要程度，这就是模型要学的参数；
    • 偏置 $b$：一个基础分，类似校准时调的零点；
    • 激活函数：一个"要不要输出"的判断规则，下面马上讲。

    想想车间里的称重分拣：传送带上按重量把零件分到合格筐和超重筐，判断规则是"重量 > 阈值 → 超重筐，否则 → 合格筐"。一个神经元干的就是这件事——加权求和相当于把各项指标综合成一个分数，阈值判断相当于"过线就输出 1，不过线输出 0"。神经元是模型里最基本的"小工位"：它只做一个动作，但很多小工位串联起来，就能做很复杂的活。

    5.1.2 为什么一层不够

    一个神经元是一条直线判断（线性分类）。可现实里很多问题不是直线能切开的。经典的例子是异或（XOR）问题：输入两个 0/1，相同输出 0、不同输出 1。四个点的分布是"对角两堆"，一条直线怎么摆都切不开。

    图纸上你见过这种尴尬：一个平面上两种孔位，左边一堆、右边一堆，一条中心线就能分开（线性可分）；可如果是"左上和右下是一组、右上和左下是另一组"，就必须画一条折线。折线 = 两段直线拼起来 = 两个神经元级联。

    所以网络要有"层"：第一层每个神经元负责一段判断，第二层把第一层的判断再组合。层数越多，能表达的"折线"越复杂。这就是"神经网络"里"网络"的含义——大量简单判断单元分层协作。

    5.1.3 激活函数：给网络"非线性"的能力

    你可能已经注意到：如果每个神经元只是"加权求和"，那不管叠多少层，本质上还是一大串加减乘除，等价于一条直线（线性）。想让网络能表达折线、曲线，必须在每层输出上加一个"非线性开关"——这个开关就是激活函数（Activation Function）。

    最常用的激活函数叫 ReLU，规则极其简单：

    ReLU(x) = x 如果 x > 0，否则 0

    翻译成车间语言："输出为正是多少就多少，输出为负就一律归零"。就像一个质检判定：读数合格（正）就记录，不合格（负）就记为 0。别看规则简单，正是这个"负数归零"让网络有了弯折能力——每一层都能把输入"掰弯"一下，很多层叠起来就能拟合任何形状的规律。

    5.1.4 从"写规则"到"学权重"：参数在哪里

    回到第 4 章 4.1 的对比：传统编程是人写规则（if 直径 > 20 then 不合格），机器学习是数据教规则（模型自己找阈值）。在神经网络里，这个"规则"就是成千上万个权重 $w$ 和偏置 $b$。

    训练神经网络 = 调整这几万个权重，让输出和真实答案越来越接近。 剩下唯一的问题是：怎么调？这就是 5.2 节的内容。

    5.2 训练的本质：损失函数与梯度下降

    5.2.1 损失函数：量化"错多少"

    第 4 章 4.6 讲过，损失函数（Loss Function） 衡量"预测和真实值差多少"，数值越大错得越多。神经网络训练的第一步就是"打分"：拿当前参数算一遍预测，再和真实答案对比，得一个损失值。

    比如用网络预测"轴的重量 = f(直径)"，真实重量 3.2kg，网络预测 3.5kg，差了 0.3kg。把所有样本的差距平方求平均，就是均方误差（MSE）损失。损失像装配后的测量偏差：偏差大，说明参数还没调好。

    5.2.2 梯度下降：朝误差最小的方向调参

    有了"错多少"的分数，下一步就是怎么改参数让分数变小。方法叫梯度下降（Gradient Descent），思路和你在山上下坡找谷底一模一样：

    • 站在这座"误差山"的某个高度（当前损失）；
    • 往四周试一下哪个方向是下坡（算梯度：误差对每个参数的偏导数）；
    • 朝下坡方向迈一步（更新参数）；
    • 重复，直到走到谷底（损失不再明显下降）。

    每步迈多大，由学习率（Learning Rate）决定——学习率是训练里最重要的旋钮之一：步长太大，会在谷底两边来回震荡、永远到不了底；步长太小，走几百步还在半山腰。后面 5.6 你会亲眼看到这两种失败的样子。

    5.2.3 反向传播：误差怎么"倒着传"回每一层

    神经网络有几层、几十层，参数成千上万。问题是：输出层的误差，该怪哪一层的哪个权重？ 这靠反向传播（Backpropagation）：从输出端开始，把误差沿着网络"往回传"，每经过一层就按链式法则算出"这层权重该往哪调、调多少"。

    你不用推公式——现代框架（5.5 节的 PyTorch）一行 loss.backward() 就把所有梯度算好了。你要建立的是直觉：误差像不合格品的追溯单，从成品往回倒查每道工序的责任。这个机制决定了网络每一层都会收到"该你调多少"的指令。

    5.2.4 一次完整训练循环

    把上面串起来，训练一圈就是四步，之后无限重复：

    前向传播（算预测） → 算损失（量差距） → 反向传播（算梯度） → 更新参数（沿梯度走一步）

    跑一下代码 5-1：一个神经元，不靠任何框架，用 NumPy 把这四步手写出来，亲眼看着损失从 67 降到 0.037、学到的权重逼近真值。这一段是全书理解"训练"最重要的一课，值得逐行读。

    # -*- coding: utf-8 -*-
"""
05-1 手写一个神经元：用梯度下降学出一条直线
------------------------------------------------
目标：让一个神经元（y = w*x + b）自己"学会" y ≈ 2x + 1。
不依赖任何深度学习框架，只用 NumPy，把
"前向 → 算损失 → 求梯度 → 更新参数"四步走一遍，就完成了"训练"。
运行：python 05-1_neuron_numpy.py
"""
import numpy as np

# 1) 造数据：x 从 0 到 6，y = 2x + 1，加一点噪声模拟测量误差
np.random.seed(0)
x = np.arange(0, 7, dtype=float)                    # [0, 1, 2, 3, 4, 5, 6]
y_true = 2.0 * x + 1.0 + np.random.normal(0, 0.2, size=len(x))

# 2) 初始化：权重 w 和偏置 b 从 0 起跑
w, b = 0.0, 0.0
lr = 0.05    # 学习率：每次参数更新的步长，太大震荡、太小太慢

def forward(x, w, b):
    """前向：算预测值 y_pred = w*x + b"""
    return w * x + b

def calc_loss(y_pred, y_true):
    """损失：均方误差 MSE，衡量"错多少"（数值越大错得越多）"""
    return np.mean((y_pred - y_true) ** 2)

# 3) 训练循环：前向 → 算损失 → 求梯度 → 更新，共 300 轮
for step in range(300):
    y_pred = forward(x, w, b)                       # 前向
    err = y_pred - y_true                           # 每个点的误差
    dw = np.mean(2 * err * x)                       # 损失对 w 的梯度
    db = np.mean(2 * err)                           # 损失对 b 的梯度
    w -= lr * dw                                    # 更新：朝损失变小的方向走一步
    b -= lr * db
    if step % 50 == 0:
        print(f"step {step:3d}  loss={calc_loss(y_pred, y_true):.4f}  w={w:.3f}  b={b:.3f}")

# 4) 结果对照：学到的 w、b 应逼近真值 2.0 和 1.0
print("-" * 42)
print(f"学到的 w = {w:.3f}（真值 2.0），b = {b:.3f}（真值 1.0）")
print(f"最终损失 = {calc_loss(forward(x, w, b), y_true):.4f}")

    本段做什么：用 NumPy 手写一个神经元，把"前向 → 损失 → 梯度 → 更新"四步训练循环完整走一遍，观察损失逐轮下降。 运行前要装什么：只需 NumPy（第 3 章已装）。运行：python 05-1_neuron_numpy.py

    真实运行输出：

    step   0  loss=67.4808  w=2.950  b=0.721
step  50  loss=0.0470  w=2.010  b=1.124
step 100  loss=0.0375  w=1.979  b=1.259
step 150  loss=0.0370  w=1.971  b=1.290
step 200  loss=0.0370  w=1.970  b=1.297
step 250  loss=0.0370  w=1.969  b=1.298
------------------------------------------
学到的 w = 1.969（真值 2.0），b = 1.299（真值 1.0）
最终损失 = 0.0370

    看三件事：损失从 67.48 一路降到 0.037；权重 w 从 0 逼近 1.969（真值 2.0）；偏置 b 逼近 1.299（真值 1.0，因为有噪声，略偏高）。这就是"训练"的全部：不断看差距、找方向、迈一步。代码 5-3 里你会看到，换成 PyTorch 后这四步浓缩成四行，但本质完全一样。

    5.3 卷积神经网络 CNN：机器如何"看"图片

    5.3.1 图像在计算机里是什么

    先解决一个朴素的问题：图像在电脑里长什么样？一张灰度图就是一个数字矩阵——每个格子（像素）存一个 0~1（或 0~255）的亮度值。彩色图就是三个这样的矩阵叠在一起（红绿蓝三个通道）。一张 224×224 的灰度图，就是 224×224=50176 个数字。

    麻烦在这：如果把这些数字全部直接当成神经网络的输入（用 5.1 的全连接结构），第一个隐藏层 100 个神经元就要 500 万个权重参数——又慢又容易过拟合。而且，"像素在哪个位置"这个空间信息会全丢：把图打乱成一行数，网络看不出来"这块亮斑在左上角还是右下角"。

    5.3.2 卷积核：局部小窗口扫描找特征

    CNN 的解法很朴素：别一次性看整张图，用一个小的"窗口"（卷积核）在图上滑着看。卷积核（Kernel） 是一个小矩阵，比如 3×3，在图上每个位置和对应的小块做"逐元素相乘再求和"，得到一个新值；滑完一整圈，就得到一张新的"响应图"。

    这像质检员用放大镜看零件：不整张图一起看，而是一个小窗口一个小窗口地扫，每个窗口只看局部。核里的数字（权重）决定了"这个窗口在找什么"——如果核的中间列是 0、两边一正一负，它就在找竖直方向的亮度跳变，也就是竖直边缘。核扫过一条竖线时，响应最大；扫过纯色背景时，响应为 0。

    跑代码 5-2 亲眼看一下：一张 8×8 的模拟零件图（中间一条竖线、一个亮点），用一个 3×3 边缘检测核扫一遍，输出里"亮点和竖线两侧"响应最强，纯背景响应为 0；再做一次 2×2 最大池化，图缩小一半。

    # -*- coding: utf-8 -*-
"""
05-2 用 NumPy 手动做一次卷积：让机器"看"出边缘
------------------------------------------------
一张 8×8 的小图（0~1 灰度，模拟零件表面），中间有一条竖直亮线。
用一个 3×3 的"边缘检测核"扫过全图，竖线处响应最强；
再做一次 2×2 最大池化，把图缩小一半。
运行：python 05-2_conv_kernel.py
"""
import numpy as np

# 1) 造一张 8×8 的"零件表面图"：背景 0.4，第 5 列一条竖线 0.9，一个亮点 0.9
img = np.full((8, 8), 0.4)
img[:, 4] = 0.9      # 竖直亮线（模拟划痕）
img[2, 2] = 0.9      # 一个小亮点（模拟点状缺陷）

# 2) 3×3 边缘检测核（Sobel 竖边缘）：左右两侧差得越多，响应越强
kernel = np.array([
    [-1, 0, 1],
    [-2, 0, 2],
    [-1, 0, 1],
])

# 3) 卷积：核在图上滑过，每个位置做"逐元素相乘再求和"
h, w = img.shape
out = np.zeros((h - 2, w - 2))
for i in range(h - 2):
    for j in range(w - 2):
        patch = img[i:i + 3, j:j + 3]      # 取 3×3 小窗口
        out[i, j] = (patch * kernel).sum()

# 4) 2×2 最大池化：每 2×2 块取最大值，图缩小一半
pool = np.zeros((3, 3))
for i in range(3):
    for j in range(3):
        pool[i, j] = img[i * 2:i * 2 + 2, j * 2:j * 2 + 2].max()

np.set_printoptions(precision=2, suppress=True)
print("原始图（8×8，0~1 灰度）：")
print(img)
print("\n卷积后（6×6）：竖线所在列响应最强（数值大），背景响应接近 0：")
print(out)
print("\n池化后（3×3）：每块取最大灰度，图缩小一半：")
print(pool)

    本段做什么：用 NumPy 手写一次 3×3 卷积 + 2×2 最大池化，看清"卷积核在找亮度跳变"到底是怎么算的。 运行前要装什么：只需 NumPy。运行：python 05-2_conv_kernel.py

    5.3.3 多层卷积：逐级抽象

    单个卷积核只能找一种特征（竖边、横边、某个纹理）。CNN 的做法是叠很多层：

    • 第一层：找边缘、点、小块（低层特征）；
    • 第二层：把边缘组合成纹理、角、局部图案（中层特征）；
    • 更深层：把纹理组合成"部件""缺陷"这类整体概念（高层特征）。

    层数越深，看到的越"整体"。 这正是它不需要人肉设计特征的原因——每一层的核数字都是训练学出来的，网络自己决定"看什么"。

    5.3.4 零件缺陷检测场景

    为什么 CNN 特别适合缺陷检测？因为缺陷天然是局部特征：划痕是一条线，气泡是一个斑，毛刺是一簇凸起——都只占图像的一小块。CNN 的局部窗口结构天生匹配这种问题，而且对"缺陷在图上哪个位置"不敏感（平移一下照样能检出），这正是质检需要的鲁棒性。5.7 的配套项目就是它的最小落地版。

    5.4 序列模型：RNN/LSTM 概念级

    5.4.1 为什么需要"记忆"

    图像是"一张图"，可很多工业数据是一串按时间排列的值：振动信号、温度曲线、刀具磨损趋势、能耗序列。这类数据叫序列（sequence）。第 4 章的分类是把每个样本当独立点看；可序列里前后的关系才是关键——同一个振动幅值 0.5，前面是平稳段还是上升段，含义完全不同。

    直觉很好建立：看趋势图时，你一定是结合前一段判断当前点——"从 0.3 慢慢爬到 0.5"和"从 0.9 掉到 0.5"，后者更像要出问题。序列模型要学的就是这种"结合前文"的能力。

    5.4.2 RNN：逐段读、记住前面

    循环神经网络（RNN, Recurrent Neural Network） 的思路很直接：网络在读完每一段后，把"这一段的信息"留一个摘要（隐藏状态），读下一段时带着前面的摘要一起读。就像你读振动曲线：不是每次只看一个点，而是脑子里带着"前面走了什么形"往下读。

    关键概念：隐藏状态（Hidden State）——网络对"到目前为止看到的东西"的压缩记忆，每读一段更新一次，逐段传递。

    5.4.3 LSTM：能记住更长的历史

    RNN 有个毛病：记忆"传不了太远"——读了几十段之后，开头的信息基本被冲淡了（梯度消失）。LSTM（Long Short-Term Memory，长短期记忆网络） 在 RNN 上加了一套"门"机制，用三个门决定：这段信息记不记、旧记忆忘不忘、什么时候输出。

    不用记公式。你只要记住它的角色：RNN 是"逐段读、会记前文"，LSTM 是"能记更长前文的 RNN 升级版"。在振动监测、刀具磨损这类需要看长趋势的工业场景，LSTM 比普通 RNN 稳得多。

    5.4.4 工程师视角：什么时候会用到

    序列模型在工业里的典型场景：设备振动趋势预警（把一段振动波形喂进去，判断"正常 / 异常前兆"）、刀具磨损状态估计（切削力时序 → 磨损等级）、能耗异常检测（电耗曲线 → 是否异常）。

    这里要预告一句（第 6 章展开）：处理语言这类序列时，现在的主流已经不是 RNN，而是 Transformer（第 6 章的注意力机制）——它更擅长并行处理和长距离记忆。本章只为你建立"序列 → 记忆"的直觉，这个直觉在第 6 章会直接派上用场。

    5.5 训练循环模板：PyTorch 快速上手

    5.5.1 框架是什么

    5.2 节你手写了一个神经元——四步循环（前向、损失、反向、更新）完全透明。但真实网络有几万、几百万个参数，手写反向传播会写到怀疑人生。深度学习框架（Deep Learning Framework）就是别人写好的"神经网络工具箱"：你只管搭模型、选损失、选优化器，反向传播和梯度计算它全包了。

    PyTorch 是当下最主流、资料最全的框架（第 6 章的大语言模型、第 8 章的智能体生态都围绕它转）。装 CPU 版即可跑通本章所有代码：

    pip install torch --index-url https://download.pytorch.org/whl/cpu

    5.5.2 五步模板

    用 PyTorch 训练网络，永远是这个五步模板，照抄改参数就行：

    ① 数据加载 → ② 定义模型 → ③ 定义损失与优化器 → ④ 训练循环 → ⑤ 保存模型

    跑代码 5-3：一个 2 层小网络拟合 y = 2x + 1。注意 5.2 节手写版和这里的对应关系：loss.backward() 就是反向传播，optimizer.step() 就是更新参数——四步循环压缩成了两行，本质没变。

    # -*- coding: utf-8 -*-
"""
05-3 PyTorch 五步法：把"训练一个网络"变成五步模板
------------------------------------------------
第 5.5 节的模板：数据 → 模型 → 损失与优化器 → 训练循环 → 保存模型。
本例用 2 层小网络拟合 y = 2x + 1。
需要先装 PyTorch（CPU 版即可）：
    pip install torch --index-url https://download.pytorch.org/whl/cpu
运行：python 05-3_pytorch_five_steps.py
"""
import torch
import torch.nn as nn

# ① 数据：造 11 个点，y = 2x + 1
x = torch.arange(0, 11, dtype=torch.float32).view(-1, 1)   # 列向量 [0..10]
y_true = 2.0 * x + 1.0

# ② 模型：输入 1 个数 → 隐层 8 个神经元（ReLU 激活）→ 输出 1 个数
model = nn.Sequential(
    nn.Linear(1, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
)

# ③ 损失与优化器
loss_fn = nn.MSELoss()      # 均方误差：衡量"错多少"
# 为什么用 Adam 而不是 SGD？ReLU 网络对步长很敏感，SGD 容易卡在局部极小
#（步长太大震荡、太小不动）；Adam 自动调节每一步的步长，省心很多。
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# ④ 训练循环：前向 → 算损失 → 清梯度 → 反向 → 更新，共 800 轮
for step in range(800):
    y_pred = model(x)                      # 前向
    loss = loss_fn(y_pred, y_true)         # 损失
    optimizer.zero_grad()                  # 清空上一步的梯度
    loss.backward()                        # 反向传播：自动算每一层梯度
    optimizer.step()                       # 更新参数
    if step % 160 == 0:
        print(f"step {step:3d}  loss={loss.item():.4f}")

# ⑤ 保存模型（之后加载回来就能直接预测）
torch.save(model.state_dict(), "model_05-3.pt")
print("-" * 42)
print(f"输入 10 时预测值 = {model(x[-1]).item():.3f}（真值 21.0）")
print("模型参数已保存到 model_05-3.pt")

    本段做什么：PyTorch 五步法最小示例——2 层网络拟合 y=2x+1，损失从 151 降到 0.003，模型参数保存成文件。 运行前要装什么：pip install torch --index-url https://download.pytorch.org/whl/cpu。运行：python 05-3_pytorch_five_steps.py

step 320  loss=0.0145
step 480  loss=0.0063
step 640  loss=0.0031
------------------------------------------

    5.5.3 张量：框架里的"数字容器"

    代码里出现的 torch.tensor 叫张量（Tensor）——你可以直接把它理解成第 3 章 NumPy 数组的"深度学习版"：长得一样、算得一样，额外好处是能自动记录计算过程（所以 loss.backward() 能自动算梯度）、能在 GPU 上跑得更快。张量 = 带"梯度记忆"和"GPU 加速"的数组，这个理解够用一整章。

    5.5.4 工程师视角：模板的意义

    五步模板的价值在于把"训练一个网络"从科研题变成填空题：换数据（第 ① 步）、换模型结构（第 ② 步）、调学习率（第 ③ 步），其余骨架不变。第 5.7 节的配套项目就是只改前两步、模板不动跑出来的。这也是你后面读任何深度学习代码时最值得先找的"骨架"。

    5.6 训练实战要点

    5.6.1 数据划分三件套：训练 / 验证 / 测试

    第 4 章讲过把数据分成训练集和测试集。深度学习还要加一个：验证集（Validation Set）。三者的分工：

    集合 用途 什么时候用
    训练集 模型在上面学（更新参数） 每轮训练
    验证集 调超参数（学习率、网络大小）时看效果 训练过程中反复看
    测试集 最终验收，衡量模型真实水平 只允许碰一次

    铁律：测试集只能碰一次。如果拿测试集反复调参，模型就"记住了考题"，测试分数虚高。训练和验证之间的比例常见 8:1:1 或 7:2:1。

    配套项目 05-4 里有一个真实的坑：合成数据按类别排列生成，如果切分前不打乱（shuffle），训练集取前 300 张、测试集取后 60 张，结果测试集里只有一类图，准确率假高得离谱（我们实际踩到过：测试集 60 张全是"气泡"，模型全预测成气泡就拿了 98%）。切分数据前必须先打乱，再按比例切——代码里那行 np.random.permutation 就是干这个的。

    5.6.2 硬件：训练要多大的机器

    先破除一个误解：不是所有训练都要"大机器"。CPU 能训练小模型——本章配套项目的 CNN 在普通笔记本 CPU 上 60 轮只要几秒钟。需要 GPU 的是大模型 + 大数据：显存（GPU 内存）用来装模型和数据，装不下就会报"Out of Memory"（显存溢出）。

    你可以这样理解：显存是模型和数据的"临时工位"，工位不够就放不下（换小模型、减小批大小 Batch Size、减小图像尺寸都能腾工位）。本章全部代码 CPU 可跑，别被"深度学习=烧显卡"的说法劝退。

    5.6.3 训练日志怎么看：损失曲线

    训练时每轮打印的 loss 就是你最该盯的仪表。常见四种形态：

    曲线形态 含义 该怎么办
    平滑下降后走平 正常收敛 继续或提前停（损失不再降就可以停）
    剧烈震荡、不降 学习率太大 调小学习率（0.01 → 0.001）
    训练损失降、验证损失升 过拟合（背答案了） 加数据、减小模型、加正则（呼应第 4 章 4.6）
    一开始就几乎不动 学习率太小或代码 bug 调大学习率，或检查数据/模型有没有接错

    5.6.4 常见失败信号排查表

    训练失败的信号五花八门，但根因就那么几类，按顺序查：

    1. 损失不降：先查数据（标签对不对、有没有打乱、有没有归一化），再查学习率（太大震荡、太小不动），最后查代码（模型和损失有没有接错）；
    2. 损失变成 NaN：学习率太大导致数值爆炸，调小学习率；
    3. 验证集指标明显差于训练集：过拟合，减小模型或加数据；
    4. 训练极慢：数据没向量化（逐样本循环）或模型太大，CPU 上把 Batch Size 调小。

    工程师贴士：训练失败先查什么？ 固定顺序——数据 → 学习率 → 代码。我们踩过的坑里，十次有八次是数据的问题（没打乱、标签错、单位没统一），只有两次真是模型的问题。先把数据查明白，再动模型。

    5.7 配套项目：零件表面缺陷图像分类

    把这一章的知识串起来，做本章的完整项目。这是本书第 2 个"能交差"的项目。

    5.7.1 需求拆解

    输入一张 16×16 的灰度"零件图"，输出它的类别：正常（normal）/ 划痕（scratch）/ 气泡（bubble）。数据是程序生成的合成图（零下载依赖、完全可复现）：正常类是一张随机灰度图，划痕类中间有一条暗线，气泡类有一个暗圆斑——模拟"表面有缺陷"。

    5.7.2 为什么用合成数据

    真实工业缺陷数据集（如钢铁表面缺陷、PCB 焊点）需要下载和标注，对入门读者有门槛。合成数据把问题简化到"只练深度学习功夫"：你能完整走通"造数据 → 建模型 → 训练 → 评估"全流程，逻辑和真实项目一模一样。进阶时把合成函数换成真实图片目录即可，代码骨架不用改。

    5.7.3 实现：五步模板套用

    模型就是 5.3 节讲的 CNN：两层"卷积 + 池化"，再接全连接输出 3 个类别分数。评估沿用第 4 章 4.5 的指标：准确率 + 混淆矩阵。

    # -*- coding: utf-8 -*-
"""
05-4 配套项目：零件表面缺陷图像分类（简化版）
------------------------------------------------
数据：程序生成的 16×16 灰度"零件图"，三类——normal（正常）、
scratch（划痕：一条暗线）、bubble（气泡：一个暗圆斑）。
模型：一个很小的 CNN（卷积 → 池化 → 卷积 → 全连接）。
目标：训练后能在测试集上给出准确率与混淆矩阵。
零下载依赖：数据是合成的、可复现。
需要先装 PyTorch（CPU 版即可）。
运行：python 05-4_defect_cnn.py
"""
import numpy as np
import torch
import torch.nn as nn

torch.manual_seed(0)
np.random.seed(0)

# ---------- 1) 合成数据：三类 16×16 灰度图 ----------
def make_image(label, rng):
    """生成一张 16×16 图：normal=均匀噪声；scratch=暗线；bubble=暗圆斑"""
    img = rng.uniform(0.35, 0.7, (16, 16))          # 背景：随机灰度
    if label == 1:                                   # 划痕：一条暗线
        c = rng.integers(2, 14)
        img[:, c] = 0.15
    elif label == 2:                                 # 气泡：一个暗圆斑
        cy, cx = rng.integers(5, 11, size=2)
        yy, xx = np.mgrid[0:16, 0:16]
        img[(yy - cy) ** 2 + (xx - cx) ** 2 <= 4] = 0.15
    return img

rng = np.random.default_rng(0)
xs, ys = [], []
for label in range(3):                               # 0=正常 1=划痕 2=气泡
    for _ in range(120):                             # 每类 120 张
        xs.append(make_image(label, rng))
        ys.append(label)
X = np.array(xs, dtype=np.float32).reshape(-1, 1, 16, 16)   # N×1×16×16
Y = np.array(ys, dtype=np.int64)

# 切分前必须打乱！否则同类的图挤在一起，测试集可能只剩一类
idx = np.random.permutation(len(X))
X, Y = X[idx], Y[idx]
n_train = 300
X_train, Y_train = torch.tensor(X[:n_train]), torch.tensor(Y[:n_train])
X_test, Y_test = torch.tensor(X[n_train:]), torch.tensor(Y[n_train:])
print(f"训练集 {X_train.shape[0]} 张，测试集 {X_test.shape[0]} 张（正常/划痕/气泡）")

# ---------- 2) 模型：很小的 CNN ----------
model = nn.Sequential(
    nn.Conv2d(1, 4, 3), nn.ReLU(), nn.MaxPool2d(2),   # 16→14→7
    nn.Conv2d(4, 8, 3), nn.ReLU(), nn.MaxPool2d(2),   # 7→5→2
    nn.Flatten(),
    nn.Linear(8 * 2 * 2, 3),                          # 2×2×8 → 3 类
)
loss_fn = nn.CrossEntropyLoss()                       # 分类损失
optimizer = torch.optim.Adam(model.parameters(), lr=0.02)

# ---------- 3) 训练 60 轮 ----------
for epoch in range(60):
    model.train()
    y_pred = model(X_train)
    loss = loss_fn(y_pred, Y_train)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    if epoch % 12 == 0:
        acc = (model(X_train).argmax(1) == Y_train).float().mean().item()
        print(f"epoch {epoch:2d}  loss={loss.item():.4f}  训练准确率={acc:.2%}")

# ---------- 4) 测试集评估 ----------
model.eval()
with torch.no_grad():
    pred = model(X_test).argmax(1)
acc = (pred == Y_test).float().mean().item()
print("-" * 44)
print(f"测试集准确率 = {acc:.2%}")

# 混淆矩阵（行=实际，列=预测）
cm = np.zeros((3, 3), dtype=int)
for t, p in zip(Y_test.numpy(), pred.numpy()):
    cm[t, p] += 1
print("混淆矩阵（行=实际：正常/划痕/气泡；列=预测）：")
print(cm)

    本段做什么：配套项目完整代码——程序生成三类合成缺陷图，用小型 CNN 训练 60 轮，在测试集上输出准确率与混淆矩阵。 运行前要装什么：PyTorch（CPU 版即可，安装命令见 5.5 节）。运行：python 05-4_defect_cnn.py

    5.8 传统机器学习 vs 深度学习：什么时候用哪个

    学完本章你可能会冲动：以后所有问题都上深度学习！——先别。能查表、能解释、数据量不大时，传统机器学习往往更好。决策表：

    维度 传统机器学习（第 4 章） 深度学习（本章）
    数据类型 表格数据（行×列） 图像、序列、高维数据
    数据量 几百到几千条就够 通常要更多数据（或靠预训练模型）
    可解释性 高（决策树能讲清"为什么"） 低（黑盒，难说清"为什么"）
    硬件要求 普通电脑即可 大模型需要 GPU，小模型 CPU 也行
    训练时间 秒级~分钟级 分钟级~天级
    特征工程 常需要人工设计特征 网络自动学特征

    工程师贴士：什么时候用传统机器学习、什么时候用深度学习？ 三条经验法则：①数据是表格、量不大、要解释 → 传统机器学习；②数据是图像 / 信号 / 文本，或特征实在设计不出来 → 深度学习；③不确定时先跑传统机器学习当基线——如果传统方法已经够用，没必要上深度学习。深度学习是"数据 + 算力换能力"，账要算清楚再上。

    5.9 常见坑与练习

    常见坑：

    • 一上来就上深度学习：数据量不够时效果反而不如第 4 章的传统机器学习（特征设计 + 小数据 = 传统 ML 的舒适区）；
    • 学习率没调对：损失不降（太小）或剧烈震荡（太大），先按 5.6.4 顺序查；
    • 数据没打乱就切分：测试集只剩一类，指标假高（05-4 我们真实踩过）；
    • 只训不评：没有验证集、不画混淆矩阵就说"能用了"；
    • 忽视硬件：模型和批大小超出显存直接崩溃，先缩小再谈精度。

    练习与验收标准：

    • 练习 1：把 05-1 的学习率从 0.05 改成 1.0 和 0.0001 各跑一次，观察损失曲线的震荡和停滞——两种失败形态亲眼见一次就不怕了；
    • 练习 2：把 05-4 换成"螺栓螺纹缺陷分类"——把合成函数改成"螺纹局部有缺口 / 正常"，改类别名跑通；
    • 练习 3：同一份第 4 章的表格数据，用决策树和本章网络各跑一次，对比准确率和"能不能说清为什么"。
    • 验收标准："能讲清"——向同事解释为什么深度学习适合图像和序列、CNN 和 RNN 各解决什么问题；"能跑通"——独立跑通缺陷分类项目，能讲出训练准确率和混淆矩阵各代表什么。

    本章小结（5 句）：神经网络是大量"加权求和 + 激活函数"的小单元分层堆叠，训练的本质是"前向 → 损失 → 反向 → 更新"四步循环加梯度下降调参；CNN 用卷积核局部扫描、适合图像缺陷检测，RNN/LSTM 逐段读序列、适合振动信号等时序数据；PyTorch 五步模板（数据 → 模型 → 损失 → 循环 → 保存）把训练变成照抄改参；训练要盯验证集和损失曲线，失败按"数据 → 学习率 → 代码"的顺序排查；数据量不足时传统机器学习更稳，深度学习是"数据 + 算力换能力"。
