## 维护规则

1. **术语三件套**：每条术语必须包含——英文原名、中文译名、一句话解释、工程类比（参见写作风格指南第六节）。
2. **首次出现即入库**：正文某术语首次出现时，同时补录术语表；正文与术语表同步更新。
3. **唯一权威源**：以飞书在线表格为准（[在线表](https://my.feishu.cn/sheets/BpYiszLTzh6s3btGCOacj03Vn4f)），每次更新后同步导出到 `术语表.md` 与 `terms.csv`。
4. **增量节奏**：每完成一章正文 v0.1，即补齐该章术语并更新本矩阵的状态列。
